# Play! South Wales

Event schedule, league map and player rankings for the Pokémon TCG and VGC
communities across South Wales.

Built with TanStack Start (React), Tailwind CSS, Clerk for admin sign-in, and
Drizzle on Cloudflare D1, deployed to Cloudflare Workers.

> The app is mid-migration. The previous FastAPI + React implementation lives
> in `deprecated/` for reference while pages are ported.

## Getting started

Open the repo in the dev container, or set it up manually:

```bash
npm ci
cp .env.example .env.local   # then add your Clerk keys
npm run cf-typegen           # generates worker-configuration.d.ts
npm run db:migrate:local
npm run dev                  # http://localhost:3000
```

## Scripts

| Script | What it does |
| --- | --- |
| `npm run dev` | Start the dev server on port 3000 |
| `npm run build` | Production build |
| `npm run check` | Biome lint and format check |
| `npm run cf-typegen` | Regenerate Worker binding types after editing `wrangler.jsonc` |
| `npm run db:generate` | Generate a migration from `src/db/schema.ts` |
| `npm run db:migrate:local` | Apply migrations to the local D1 database |
| `npm run db:migrate:remote` | Apply migrations to the production D1 database |
| `npm run db:studio` | Browse the local database with Drizzle Studio |
| `npm run deploy` | Build and deploy to Cloudflare Workers |

## Environment

Copy `.env.example` to `.env.local` and fill in `VITE_CLERK_PUBLISHABLE_KEY`
and `CLERK_SECRET_KEY`. In production, set the secret with
`wrangler secret put CLERK_SECRET_KEY`.

## Project layout

- `src/routes/` — file-based routes (`routeTree.gen.ts` is generated)
- `src/db/` — Drizzle schema and D1 client
- `migrations/` — SQL migrations generated by Drizzle
- `wrangler.jsonc` — Worker and D1 configuration
